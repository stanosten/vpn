# ⚡ Async IP Network Checker & Auto-Updater

Высокопроизводительный асинхронный инструмент сканирования и валидации IPv4-адресов и CIDR-сетей с автоматической периодической проверкой через **GitHub Actions** и сохранением рабочих адресов.

Работает исключительно на базе **стандартной библиотеки Python** (`asyncio`, `socket`, `ipaddress`, `urllib`, `time`, `re`), не требуя установки сторонних пакетов.

---

## 📁 Структура проекта

```text
├── .github/
│   └── workflows/
│       └── checker.yml      # CI/CD воркфлоу для запуска по Cron и авто-коммита
├── checker.py               # Основной асинхронный скрипт сканирования (Python StdLib)
├── sources.txt              # Список URL источников со списками IP / CIDR
├── working-ips.txt          # Сгенерированный список доступных IP (сортировка по RTT)
├── requirements.txt         # Файл зависимостей (только stdlib)
└── README.md                # Документация проекта
```

## ⚙️ Принцип работы `checker.py`

1. **Загрузка источников:**
   - Читает прямые ссылки (raw URLs) из `sources.txt`, пропуская пустые строки и комментарии (`#`).
   - Загружает данные с кастомным заголовком `User-Agent`.

2. **Парсинг и сетевая фильтрация:**
   - Извлекает IPv4-адреса и CIDR-диапазоны с помощью регулярных выражений.
   - Валидирует адреса через модуль `ipaddress`: отсекает приватные (`10.0.0.0/8`, `192.168.0.0/16`, `172.16.0.0/12`), loopback (`127.0.0.0/8`), multicast (`224.0.0.0/4`), link-local и зарезервированные диапазоны.
   - **Защита от OOM:** подсети больше `/24` (например `/16` или `/8`) не разворачиваются целиком во избежание переполнения памяти — берется первый рабочий шлюз/хост. Для сетей `/24`..`/32` разворачиваются все доступные хосты.
   - Дедуплицирует адреса с помощью `set`.

3. **Асинхронная проверка доступности:**
   - Использует неблокирующий `asyncio.open_connection` на целевой TCP-порт (`443` по умолчанию).
   - Ограничивает пул одновременных соединений через `asyncio.Semaphore(400)`.
   - Таймаут на один узел — не более `1.2` секунды.
   - Замеряет время отклика (RTT / latency в мс) для каждого успешного подключения.

4. **Экспорт и отчет:**
   - Ответившие адреса сортируются по возрастанию задержки (самые быстрые вверху).
   - Результат сохраняется в `working-ips.txt`.
   - Выводится подробная статистика и лог прогресса.

## 🚀 Локальный запуск

### 1. Требования
- Python **3.11+** (или Python 3.9+)
- Никаких внешних `pip install` не требуется.

### 2. Запуск сканирования

```bash
# Базовый запуск со стандартными параметрами:
python checker.py

# Запуск с переопределением параметров (порт, пул, таймаут):
python checker.py --port 443 --concurrency 400 --timeout 1.2 --sources sources.txt --output working-ips.txt
```

## 📝 Настройка источников (`sources.txt`)

Добавляйте прямые ссылки на текстовые файлы с IP-адресами или CIDR-списками (по одной ссылке на строку):

```text
# Ссылка на проверенный белый список CIDR
https://raw.githubusercontent.com/igareck/vpn-configs-for-russia/refs/heads/main/WHITE-CIDR-RU-checked.txt

# Пример добавления собственного источника
# https://raw.githubusercontent.com/username/my-repo/main/ips.txt
```

## 🤖 Настройка GitHub Actions (Автономная работа)

Проект полностью настроен для автономной периодической работы через GitHub Actions:
- **Расписание:** запуск каждые 6 часов (`0 */6 * * *` UTC).
- **Ручной запуск:** кнопка **Run workflow** (`workflow_dispatch`).
- **Авто-коммит:** если список `working-ips.txt` изменился, GitHub Actions создаст коммит от имени `github-actions[bot]` и запушит обновления в репозиторий.

### ⚠️ Важно: Настройка прав (Read and Write Permissions)

Чтобы воркфлоу мог отправлять изменения (`git push`) обратно в репозиторий, необходимо выдать соответствующие права:

1. Перейдите в ваш репозиторий на GitHub.
2. Откройте **Settings** (Настройки) ➔ в левом меню выберите **Actions** ➔ **General**.
3. Прокрутите страницу вниз до раздела **Workflow permissions**.
4. Выберите пункт **Read and write permissions** (Разрешения на чтение и запись).
5. Поставьте галочку напротив **Allow GitHub Actions to create and approve pull requests** (по желанию).
6. Нажмите кнопку **Save** (Сохранить).

```text
GitHub Repository ──► Settings ──► Actions ──► General ──► Workflow permissions ──► [x] Read and write permissions
```

После этого GitHub Actions сможет автоматически обновлять `working-ips.txt` без необходимости настройки персональных токенов (PAT).
